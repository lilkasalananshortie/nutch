# Nutch v0.5.0 Beta

## Highlights

This beta focuses on a polished Poppins-based interface and local productivity
workflows for classmate testing.

## Added

- Refined monochrome UI with bundled Poppins typography.
- Rebuilt expanded surface hierarchy with Nutch branding and a separated tool rail.
- Planner tags, estimated duration, and lightweight subtasks.
- Search category filters for Commands, Notes, and Tasks.
- Context activity stack, pinned activities, multiple labeled timers, Today
  briefing, Quick Capture, backup/restore, privacy mode, and local profiles.

## Improved

- Media remains compact beside the persistent clock.
- Notes, Planner, Search, Settings, and Notifications now share one visual
  language.
- Single-instance behavior and missed-reminder recovery are preserved.

## Known issues

- Unsigned beta builds may trigger SmartScreen reputation warnings.
- Portable mode, cloud calendars, AI Copilot, automations, clipboard history,
  and hardware-specific device controls are deferred.

## Testing focus

Please prioritize media detection, notch positioning, DPI scaling, reminders,
sleep/resume, startup, and duplicate-launch behavior. See `TESTING.md`.
