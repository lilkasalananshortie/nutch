# Security policy

## Supported versions

The latest `main` branch and the latest tagged release receive security
attention. Older releases may not receive fixes.

## Reporting a vulnerability

Please do not publish credentials, private data, or an exploitable proof of
concept in a public issue. Use a private GitHub security advisory for the
repository when available. If private reporting is unavailable, open a
minimal issue asking for a private contact channel without including the
vulnerability details.

Nutch does not accept API keys, signing keys, Notes, Planner exports, or
clipboard history in bug reports.
