# Nutch

Nutch is a lightweight Windows top-center Dynamic Island-inspired utility for local time, battery, real master-volume control, Windows media sessions, quick notes, alerts, and optional system widgets.

## Current capabilities

- Premium monochrome design tokens and consistent vector icon treatment
- Bundled Poppins typography with refined spacing, surfaces, focus states, and controls
- Responsive collapsed geometry with `context | clock | status` hierarchy
- Compact media context with artwork thumbnail, ellipsis, micro-progress, and reduced-motion equalizer
- Contextual expanded height so empty media does not create a giant blank panel
- Distinct top-attached Notch mode and floating Island mode with restrained motion
- Persistent quick notes with an original monochrome Notes-inspired editor
- An in-island inbox for Nutch alerts and optional native Windows notifications
- Central live-activity priority state for media, focus, reminders, battery, and volume feedback
- Persistent local Planner tasks with due-time reminder activities
- Focus sessions (25/45/60 minute presets) with pause/resume and restored live state
- Quick Search across Nutch Notes, Planner items, and allowlisted Nutch actions
- Local calculator and unit conversion from Quick Search (for example `2^8` or `20 km to miles`)
- Allowlisted command actions for volume, mute, Focus, notes, Planner, Settings, and display mode
- Minimal idle, Do Not Disturb, Presentation, and fullscreen-policy preferences
- First-run onboarding, single-instance protection, missed-reminder recovery, and non-sensitive diagnostics
- Versioned local backup/restore and privacy-aware Private Notes
- Quick Capture and a sleep-safe general Timer
- Fuzzy local Search ranking with bounded command history
- Global shortcuts: `Alt+Space` for Quick Search and `Alt+N` for Quick Capture
- Search aliases/prefixes (`vol`, `>command`, `#note`-style input) and safe privacy/DND actions
- Manual Privacy mode masks collapsed media/activity titles; notification history is bounded
- Context activity stack with pinning/cycling and multiple labeled persistent timers
- Compact Today view for current Focus, active timers, and the next Planner item
- Local profiles: Default, Work, Study, Gaming, and Presentation policies
- Planner metadata: tags, estimated duration, and lightweight subtasks
- Search category filters for Commands, Notes, and Tasks
- Local calculator and unit conversion from Quick Search (for example `2^8` or `20 km to miles`)
- Allowlisted command actions for volume, mute, Focus, notes, Planner, Settings, and display mode
- Minimal idle, Do Not Disturb, Presentation, and fullscreen-policy preferences
- Selectable Notch/Island display modes and optional collapsed mouse-wheel volume
- Island-style navigation for Notes, Planner, Search, Focus, Alerts, and Settings
- Notes are stored in the Nutch configuration directory, not the source tree

## Development

```powershell
npm install
npm run tauri dev
```

## Production build

```powershell
npm run tauri build
```

## Signed Windows build

Copy `src-tauri/tauri.signing.example.conf.json` to the ignored file
`src-tauri/tauri.signing.conf.json`, replace the certificate thumbprint with a
valid code-signing certificate installed for the current user, then run:

```powershell
npm run tauri:build:signed
```

Nutch can show native notifications after installation. Its in-island inbox contains alerts generated by Nutch; Windows does not expose other apps' private notification history to a normal unpackaged desktop utility. Media controls use
the active Windows system media session, so the player must support Windows
System Media Transport Controls.

## Architecture

The React UI owns presentation and lightweight state, while Tauri commands keep
Windows-specific work in Rust. The live-activity provider chooses one current
context by priority, so temporary volume, reminder, battery, and Focus states
can restore media or idle context. Notes, Planner items, and settings are
stored locally under the user's Nutch application configuration directory.

See [docs/architecture.md](docs/architecture.md) for the communication and
persistence boundaries.

User-facing help is in [docs/user-guide.md](docs/user-guide.md) and
[docs/troubleshooting.md](docs/troubleshooting.md). Security reporting guidance
is in [SECURITY.md](SECURITY.md).

The current boundary for the larger advanced-feature roadmap is tracked in
[docs/advanced-feature-status.md](docs/advanced-feature-status.md).

## Roadmap

Completed maturity work includes onboarding, single-instance behavior,
settings recovery, diagnostics, restart-safe reminders, versioned backup/restore,
Quick Capture, labeled timers, fuzzy Search, global shortcuts, and the Today
surface. Planned work is opt-in clipboard history, profiles, and an optional AI
action provider. Signed updates, Windows-wide downloads, microphone/camera
indicators, brightness control, and automatic fullscreen detection remain
deferred until reliable user-space APIs and release keys are available.
